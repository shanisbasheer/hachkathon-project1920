# Cyber Triage – Digital Forensics Project

## About the Project
Cyber Triage is a hackathon project designed around a digital forensics platform that aims to help digital forensic departments organise and manage investigation cases.

## Purpose
The main goal is to provide a structured platform for managing digital evidence and supporting the investigation process.

## Proposed Workflow
- Evidence Management
- Evidence Acquisition
- Data Classification
- Information Extraction
- Correlation of Findings
- Investigation

## Technologies Used
- HTML
- CSS

## Current Project Status
This project is currently an incomplete front-end prototype. The initial interface has been developed using HTML and CSS. Backend development and the complete investigation functionalities are not yet implemented.
